## Expressive shapes

Run Monet Studio and expand **Material 3 Expressive shapes**. This section shows
all 35 catalog shapes and one morph between them.

1. Select a shape to animate from the previous selection.
2. Select another shape during the animation to redirect it from the outline on
   display.
3. Use the replay, reverse, pause, and progress controls to inspect a frame.
4. Change the text, the icon size, the padding, and the stretch option to inspect
   the fit of the content.

The filled, outlined, and elevated buttons use `ExpressiveButton`. The surface,
the ink, the shadow, and `MonetClip` share one animated border. Content that is
too large for its constraints scales down. Intermediate frames of a morph can
clip.

For the API, see [Expressive buttons](../docs/expressive_buttons.md) and
[Material 3 Expressive shapes](../docs/material_expressive_shapes.md).
